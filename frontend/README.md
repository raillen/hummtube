# Frontend SPA (`frontend/`)

## O que é este diretório?
Código-fonte da interface de usuário em Single Page Application (SPA), desenvolvida com Svelte, TypeScript e Tailwind CSS.

## Para que serve?
Implementa a interface visual declarativa, o player de vídeo reativo com HLS.js, o modo de navegação espacial (Modo TV 10-foot UI) e a alternância de temas (dark/light).

## Inventário
- `src/`: Componentes Svelte, stores reativas, utilitários e CSS;
- `bin/`: Scripts auxiliares de build do frontend;
- `e2e/`: Testes ponta a ponta com Playwright;
- `package.json`: Manifesto de dependências npm do frontend.
