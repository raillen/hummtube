# Domínio Puro (`internal/domain/`)

## O que é este diretório?
Camada mais interna da Clean Architecture, contendo entidades, structs de dados e contratos essenciais de negócio.

## Para que serve?
Define modelos centrais como `Video`, `Channel`, `Playlist`, `PlaybackPlan`, sem qualquer dependência de banco de dados, bibliotecas de terceiros ou frameworks web.
