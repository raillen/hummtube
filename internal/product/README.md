# Definição de Produtos (`internal/product/`)

## O que é este diretório?
Especificação de separação dos produtos da NanoSuite (NanoTube, NanoIPTV, NanoMusic).

## Para que serve?
Define a identidade de cada aplicativo, seu nome de banco de dados, chaves do Keyring e allowlist de chamadas RPC permitidas (ADR-022).
