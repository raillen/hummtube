# Governança e Roteamento de IA (`docs/06-governance/`)

## O que é este diretório?
Diretrizes operacionais para colaboração entre desenvolvedores humanos e agentes de inteligência artificial.

## Para que serve?
Define limites de atuação, matriz de papéis de agentes e governança de documentação.

## Inventário
- `AGENT_ROLES.md`: Especializações e responsabilidades dos agentes;
- `AI_ROUTING.md`: Políticas de escolha e escalação de modelos LLM;
- `DOC_GOVERNANCE.md`: Ciclo de vida e sincronização da documentação canônica;
- `RISK_REGISTER.md`: Registro contínuo de riscos técnicos e de arquitetura.
