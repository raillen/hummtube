# Contratos de Documentação Prumo (`docs/contracts/`)

## O que é este diretório?
Definições e mapeamentos de contratos de documentação do sistema de engenharia Prumo.

## Para que serve?
Permite ao Prumo verificar formalmente via `prumo docs audit` e `prumo docs readiness` se todo conhecimento essencial de engenharia e produto está documentado.

## Inventário
- `builtin.json`: Catálogo canônico de contratos de documentação do Prumo;
- `bindings.json`: Mapeamento entre cada contrato e os arquivos de documentação reais do projeto.
