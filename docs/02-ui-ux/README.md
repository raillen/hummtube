# Interface e Experiência do Usuário (`docs/02-ui-ux/`)

## O que é este diretório?
Especificações de design system, fluxos de telas, wireframes e acessibilidade da interface.

## Para que serve?
Padroniza estilos visuais em Tailwind CSS, componentes Svelte e garante suporte completo ao Modo TV (10-foot UI).

## Inventário
- `UI_UX.md`: Princípios de design, paleta de cores, tipografia e tokens visuais;
- `FLOWS_AND_WIREFRAMES.md`: Diagramas de navegação, rotas e estados de tela;
- `ACCESSIBILITY.md`: Navegação direcional espacial (D-Pad), atalhos e diretrizes WCAG.
