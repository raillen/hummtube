# Registro de Decisões Arquiteturais (`docs/09-decisions/`)

## O que é este diretório?
Catálogo consolidado e central de decisões estruturais (ADRs) da NanoSuite.

## Para que serve?
Registra o status (aceito, proposto, rejeitado) e o histórico de evolução técnica do sistema.

## Inventário
- `DECISION_REGISTER.md`: Tabela de rastreamento com todas as ADRs, escopos e datas de aprovação.
