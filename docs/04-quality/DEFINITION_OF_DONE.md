# Critérios de Conclusão (Definition of Done)

Para uma funcionalidade ser considerada concluída:
1. Código implementado seguindo Clean Architecture e boas práticas de Go e Svelte;
2. Testes unitários implementados e passando;
3. `task verify` executa sem erros;
4. Nenhuma regressão de performance ou vazamento de memória detectado;
5. Documentação e ADRs atualizados quando aplicável.
