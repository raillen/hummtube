# Qualidade e Engenharia de Testes (`docs/04-quality/`)

## O que é este diretório?
Políticas de qualidade, estratégia de testes exaustivos e critérios de aceitação formal.

## Para que serve?
Garante que nenhum código seja integrado sem satisfazer os quality gates definidos.

## Inventário
- `TEST_STRATEGY.md`: Pirâmide de testes, execução com `-race` e quality gates;
- `DEFINITION_OF_DONE.md`: Critérios objetivos para conclusão de tarefas e PRs;
- `UI_UX_TESTS.md`: Testes automatizados de interface e conformidade visual;
- `HARDWARE_BENCHMARKS.md`: Benchmarks de referência no hardware alvo (Intel Celeron / 2GB RAM).
