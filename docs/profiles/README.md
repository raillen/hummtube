# Perfis de Documentação Prumo (`docs/profiles/`)

## O que é este diretório?
Catálogo de perfis de documentação do Prumo.

## Para que serve?
Define quais contratos de documentação são mandatórios para cada tipo de software (core-software, desktop-gui, web-application, cli).

## Inventário
- `builtin.json`: Perfis de documentação padronizados pelo framework.
