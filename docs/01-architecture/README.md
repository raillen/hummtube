# Arquitetura de Sistemas (`docs/01-architecture/`)

## O que é este diretório?
Documentação estrutural do sistema sob a ótica de Clean Architecture / Ports and Adapters.

## Para que serve?
Define topologia, boundaries, fluxo de dados e contratos entre a SPA Svelte e os serviços Go no Wails v3.

## Inventário
- `ARCHITECTURE.md`: Estilo arquitetural, camadas e integrações externas;
- `DATA_FLOWS.md`: Diagramas de fluxo de reprodução, catálogo e sincronização;
- `CONTRACTS.md`: Interfaces de serviços e contratos expostos via RPC;
- `adrs/`: Catálogo detalhado de registros de decisões arquiteturais (ADRs).
