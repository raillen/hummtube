# Atalhos de Teclado — NanoTube Web

| Atalho | Ação |
|---|---|
| `Espaço` / `K` | Play / Pause |
| `J` / `L` | Voltar / Avançar 10 segundos |
| `Seta Esquerda` / `Seta Direita` | Voltar / Avançar 5 segundos (fora do Modo TV; no Modo TV navegam o foco) |
| `Seta Cima` / `Seta Baixo` | Aumentar / Diminuir Volume (fora do Modo TV; no Modo TV navegam o foco) |
| `M` | Mutar / Desmutar Áudio |
| `F` | Alternar Tela Cheia |
| `C` | Alternar Legendas |
| `[` / `]` | Diminuir / Aumentar Velocidade (0.25x - 2.0x) |
| `N` / `P` | Próximo / Vídeo Anterior na Fila |
| `Ctrl + F` / `/` | Focar na Barra de Pesquisa |
| `Ctrl + R` | Sincronizar Inscrições (Atualizar) |
| `F10` / `Ctrl + T` | Alternar Modo TV (10-Foot UI) |
| `Esc` | Fechar modal ou sair de tela cheia |
