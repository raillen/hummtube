# Operações, Release e Diagnósticos (`docs/07-operations/`)

## O que é este diretório?
Procedimentos operacionais de build, empacotamento, distribuição e troubleshooting.

## Para que serve?
Documenta o ciclo de lançamento e suporte da aplicação em diferentes ambientes Linux.

## Inventário
- `OPERATIONS.md`: Processo de release, matriz de smoke test do system tray e referência de comandos CLI;
- `PACKAGING_AND_DISTRIBUTION.md`: Formatos de pacotes nativos (.deb, Arch, RPM, AppImage), caminhos e rollback;
- `TROUBLESHOOTING.md`: Guia de resolução de problemas e diagnósticos comuns.
