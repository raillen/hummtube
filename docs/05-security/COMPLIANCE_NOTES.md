# Notas de Conformidade — NanoTube Web

## Termos de Uso e APIs
- Utiliza a YouTube Data API v3 sob credenciais próprias do usuário ou cliente registrado para sincronização de inscrições;
- O `PlaybackResolver` opera de forma estritamente pessoal e local, sem redistribuição comercial ou download permanente de conteúdo protegido por direitos autorais.
