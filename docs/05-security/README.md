# Segurança e Confiança (`docs/05-security/`)

## O que é este diretório?
Contratos de segurança, modelagem de ameaças e diretrizes de proteção de dados e privacidade.

## Para que serve?
Estabelece requisitos invioláveis de segurança: proteção do Keyring nativo, guardas anti-SSRF, CSP e segredo de tokens.

## Inventário
- `SECURITY.md`: Princípios de segurança, isolamento RPC e proxy de mídia local;
- `THREAT_MODEL.md`: Análise de ameaças STRIDE e mitigações correspondentes;
- `COMPLIANCE_NOTES.md`: Auditoria de licenças, dependências e SBOM.
