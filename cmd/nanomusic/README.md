# Entrypoint NanoMusic (`cmd/nanomusic/`)

## O que é este diretório?
Ponto de entrada do executável **NanoMusic**.

## Para que serve?
Executável desktop dedicado à reprodução de áudio, playlists musicais e integração com Last.fm / YouTube Music.

## Inventário
- `main.go`: Ponto de entrada e bootstrap do reprodutor musical.
