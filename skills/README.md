# Habilidades Locais da NanoSuite (`skills/`)

## O que é este diretório?
Habilidades especializadas (skills) customizadas para o ecossistema do NanoTube.

## Para que serve?
Fornece instruções técnicas estruturadas para agentes sobre temas específicos do projeto:
- `nanotube-playback-resolver`: Guia procedimental sobre resolução e cascading de streams;
- `sqlite-goose-storage`: Padrões de queries FTS5 e migrações Goose;
- `wails-svelte-development`: Melhores práticas de integração Wails v3 + Svelte.
